CIRCLE FEATURE — MANUAL QA CHECKLIST

App: Witoh
Feature: Circle (social connection system)
Last updated: 2026-05-07

LEGEND
------
Priority H = High   (must pass before every deploy)
Priority M = Medium (must pass before every release)
Priority L = Low    (regression / edge case, test when time allows)

Account types
  Public  — anyone can add them; they are joined immediately, no approval needed
  Private — requests must be sent and manually accepted before circle is created

Circle direction vocabulary (for backend state notes)
  "A's circle"           = rows WHERE user_name = A
  "A joined B's circle"  = row WHERE user_name = B, member_name = A
  "mutual"               = both A→B and B→A edges exist
  "one-way"              = only one edge exists (B's circle has A, not vice versa)

Pass/Fail format
  [ ] PASS
  [ ] FAIL
