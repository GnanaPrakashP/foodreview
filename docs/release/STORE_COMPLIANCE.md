## Console declaration worksheet

- Data linked to the account: contact information, profile, user content, private room participation, identifiers, interactions and reports.
- Diagnostics: privacy-filtered crash and performance data; no tracking or advertising identifier is configured.
- Location: optional foreground/precise location for user-initiated nearby discovery; no background location.
- Photos/videos/audio: user-selected/captured content; microphone also supports private Memory voice messages.
- Push: account/install-bound tokens and minimal routing payloads; private authorization is rechecked on open.
- Moderation: reports and bounded provider/operator processing.
- Account deletion: in-app path plus public URL; asynchronous durable cleanup and backup limitations must be disclosed.
- Age rating: social/user-generated content, messaging and location require an owner-reviewed rating and moderation explanation. Product minimum is 13, but store/legal child treatment needs counsel.
- Export compliance: app config states no non-exempt encryption; owner must confirm for each submission.

Reviewer credentials must be disposable staging accounts containing synthetic content. Review notes should explain visibility classes, Memories, camera/location/microphone just-in-time prompts, push, reporting/blocking and deletion. Do not give reviewers production user access.

Qualified counsel and the release owner must approve controller/company identity, jurisdiction, exact retention, processor terms, children/age handling, copyright process, data-safety/privacy-label answers and all store-console declarations. Repository consistency is not legal or store approval.
